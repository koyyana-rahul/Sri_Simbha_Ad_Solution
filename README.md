# Sri Simbha Ad Solution — marketing site

Static single-page site for an advertising agency in Visakhapatnam. React 19 +
React Router 7 on Create React App, styled with Tailwind. There is no backend:
every page is rendered from local content and enquiries are handled over
WhatsApp, e-mail and phone.

## Commands

| Command | What it does |
| --- | --- |
| `npm start` | Dev server with HMR on <http://localhost:3000> |
| `npm run build` | Production build into `build/` |
| `npm test` | Watch mode |
| `npm run test:ci` | Single test run (used in CI) |
| `npm run lint` | ESLint over `src/**/*.{js,jsx}` |
| `npm run format` / `format:check` | Prettier write / check |
| `npm run images:report` | Current image weight, writes nothing |
| `npm run images:optimize -- --write` | Re-compress images in place, generate the OG card |

## Structure

```
src/
  app/          router, providers, theme
  config/       site, navigation and service registries  <- single source of truth
  data/         content shared by more than one page
  features/     per-page sections and their data
  pages/        one file per route (composition only)
  components/   common / layout / navigation / floating / animations
  hooks/        useMediaQuery, usePrefersReducedMotion, useEscapeKey, useLockBodyScroll
  utils/        helpers, validators, structured-data builders
  styles/       tokens, design system, animations, globals
scripts/        image optimisation
```

Two registries drive most of the site. `config/services.config.js` owns the six
services, their copy, imagery and routes — `/services`, the home preview, the
slideshow and the footer all derive from it, so adding a service is one entry
plus nothing else. `config/site.config.js` owns brand, contact details, social
profiles and the business facts that become `LocalBusiness` JSON-LD. Nothing
user-visible should be hardcoded in a component.

## Adding content

- **A service** — add an object to `config/services.config.js`. The card, the
  detail page, the breadcrumb, the `Service` schema and the sitemap entry all
  follow automatically.
- **Copy on a page** — it belongs in that feature's `data` file, not the
  component.
- **A cross-page fact** (a statistic, a value, a milestone) — `data/company.data.js`.

## Design system

`styles/design-system.css` holds the fluid type scale (`text-display`, `text-h1`
… `text-eyebrow`), the reading-measure caps and the two section rhythms. Use
those classes rather than ad-hoc `text-*` / `py-*` pairs — the scale is `clamp()`
based, so headings grow continuously instead of jumping at breakpoints.

Brand colours live in `tailwind.config.js` and are mirrored in
`styles/variables.css`. Keep the two in sync.

**Contrast:** headings use `brand-600` in light mode and `brand-400` in dark.
`brand-500` measures ~2.2:1 on white and fails the 3:1 large-text threshold, so
do not use it for text on a light surface. It is fine for icons, borders and
fills.

## Performance notes

- Every page is a separate lazy chunk. `app/routeLoaders.js` holds the loaders so
  navigation can prefetch a chunk on `pointerenter` without importing the router.
- The infinite decorative loops (marquee, background blobs, icon bob, header
  shimmer) are CSS `transform` animations, not JavaScript. Keep it that way —
  `styles/motion.css` — and add new decorative motion there.
- The hero video is skipped for `prefers-reduced-motion` and for visitors on a
  metered or 2G connection (Network Information API).
- Run `npm run images:report` after adding photos. Gallery images are served far
  larger than the ~600px they display at; `srcset` is the outstanding item.

## Accessibility and motion

One skip link, one `<h1>` per page, real landmarks, labelled controls, and a
focus-trapped lightbox that restores focus on close. `prefers-reduced-motion` is
honoured in two places: `<MotionConfig reducedMotion="user">` neutralises
framer-motion transforms, and `styles/animations.css` stops the CSS loops.

## SEO

`components/common/Seo` manages titles, descriptions, canonical and Open Graph
per route. `utils/structuredData.js` builds `LocalBusiness`, `WebSite`, `Service`,
`BreadcrumbList`, `ItemList` and `FAQPage` graphs; each is emitted from the same
array that renders the visible content, so markup cannot contradict the page.
`public/og-image.png` is generated by the image script — do not hand-edit it.

## Deployment

`vercel.json` sets the SPA rewrite, long-term caching for hashed assets, and
security headers. Deep links such as `/services/ad_films` depend on that rewrite.

Set `REACT_APP_SITE_URL` and `REACT_APP_WHATSAPP_NUMBER` in the environment; see
`.env.example`. Only `REACT_APP_`-prefixed values reach the browser, so nothing
secret belongs in either.
